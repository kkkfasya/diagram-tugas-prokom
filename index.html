TCP Port Scanner — Codebase Architecture

Penjelasan Fungsi

main.py — titik awal program

Membaca perintah dari terminal, menentukan dari mana daftar IP target berasal, menampilkan banner pembuka, lalu menyerahkan pekerjaan ke modul pemindai.

main()Menyiapkan tiga opsi perintah: -i (alamat IP target, dipisah koma atau spasi), -f (file teks berisi satu IP per baris), dan -o (folder untuk menyimpan hasil). Kalau tidak ada target sama sekali, program mencetak contoh cara pakai lalu berhenti. IP dari -f dibaca baris per baris; IP dari -i diproses oleh ip.parser.parse_ip_list(). Setelah itu program mencetak banner ASCII "PORT SCANNER" (dengan pyfiglet), daftar target, dan waktu mulai lewat print_section_header(), lalu memanggil ip.processor.scan_target_ips() untuk mulai memindai.
blok __main__Membungkus main() agar kalau kita menekan Ctrl+C di tengah pemindaian, program berhenti dengan rapi lewat pesan "[x] Exiting Program!!" tanpa menampilkan error yang berantakan.

ip/const.py

TOTAL_PORTS = 65535Angka batas jumlah port TCP yang dipindai. Ditaruh di file tersendiri supaya hanya ditulis satu kali dan dipakai bersama oleh modul lain, jadi tidak ada beda hitungan antar modul.

ip/parser.py

parse_ip_list(ip_list)Mengubah masukan -i menjadi daftar IP yang rapi. Untuk setiap masukan: kalau isinya nama file yang benar-benar ada, file itu dibaca dan setiap baris yang tidak kosong dijadikan satu target; kalau bukan file, teksnya dipisah berdasarkan koma. Hasilnya berupa daftar gabungan yang kemudian dibersihkan dari entri kosong oleh main.py.

ip/processor.py — mesin pemindai

Seluruh logika pemindaian ada di sini. Satu fungsi mengatur jalannya semuanya; tiga fungsi lainnya masing-masing mengerjakan satu langkah.

scan_target_ips(targets, output_dir)Fungsi pengatur utama. Memeriksa IP target satu per satu sambil mencetak progres ("Scanning Target (1/N)"). Untuk setiap host: cek dulu apakah host bisa dihubungi lewat connect_to_ip() — kalau gagal, host dilewati dengan pesan kesalahan; kalau berhasil, lanjut memindai port dengan check_open_ports(); lalu hasilnya disimpan oleh save_port_to_file(). Kalau penyimpanan ditolak sistem (PermissionError), hasil dicetak ke layar sebagai gantinya. Ctrl+C dan gangguan jaringan juga ditangani dengan pesan yang rapi.
connect_to_ip(target, timeout_sec=3)Tes apakah host hidup. Mencoba membuka satu koneksi ke port 80 dengan batas waktu 3 detik, lalu langsung menutupnya. Kalau gagal, host dianggap tidak bisa dihubungi dan pemindaian lanjut ke target berikutnya — jadi program tidak buang waktu memindai 65.535 port pada host yang mati.
check_open_ports(target_ip, port_count)Pemindaian sesungguhnya. Untuk setiap port dari 1 sampai TOTAL_PORTS, fungsi membuat koneksi TCP baru dengan batas waktu 1 detik dan memanggil connect_ex(). Kalau hasilnya 0, artinya koneksi berhasil dan port tersebut terbuka. Port yang terbuka dicatat dalam daftar dan langsung diumumkan di layar dengan pesan "[+] Port N is open".
save_port_to_file(target_ip, ports, output_dir)Menyimpan hasil. Kalau tidak ada port yang terbuka, fungsi mengembalikan False. Kalau ada, hasil ditulis ke file bernama open_ports_<ip>_<tanggal-jam>.txt (titik pada IP diganti tanda minus, dan mengikuti folder -o kalau diisi) dengan satu nomor port per baris, lalu mencetak pesan berhasil.

pretty_print/

Kumpulan fungsi kecil untuk merapikan tampilan teks di layar, dipakai bersama oleh main.py dan processor.

print_banner(message)Menampilkan pesan di antara dua garis "=" — dipakai untuk peristiwa penting seperti konfirmasi hasil tersimpan atau kesalahan fatal.
print_section_header(message, char='-')Pola yang sama tapi karakter garisnya bisa diganti — dipakai untuk progres pemindaian, waktu mulai, dan pesan gagal per target.

Catatan: port_scan.py di folder utama adalah versi lama program ini yang masih satu file. Struktur modul di atas adalah versi yang sudah dipisah: pembacaan masukan, pemindaian, konstanta, dan tampilan teks masing-masing punya file sendiri.
